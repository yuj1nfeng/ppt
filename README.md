# 在线教育系统 - 演讲PPT

高效、智能的一体化在线学习管理平台演示PPT。

## 在线预览

GitHub Pages: https://yuj1nfeng.github.io/ppt/

## 本地运行

```bash
# 方式1：使用启动脚本
./start.sh

# 方式2：直接启动
python3 -m http.server 10080
```

访问地址: http://localhost:10080

## 操作说明

- 点击「上一页/下一页」按钮切换
- 键盘方向键 ← → 翻页
- 空格键翻页

## 内容模块

1. 系统概述
2. 用户管理（用户、积分、等级、角色）
3. 课程管理（列表、分类、学习进度）
4. 考试管理（题库、考试、成绩、主观题评分）
5. 积分商城（商品分类、商品列表）
6. 系统管理（通知、轮播图、证书模板、设置、维护、日志）
